DENTAL STUDIO — ОБЛАЧНАЯ ВЕРСИЯ. НАЧНИТЕ ЗДЕСЬ
================================================

Это отдельная папка. Старый проект dental-studio и папку dental-studio-cloud
не обязательно удалять, но работать нужно именно с этой.

ПОРЯДОК ДЕЙСТВИЙ — 6 ШАГОВ
--------------------------

1) Создайте таблицы в базе
   Откройте supabase.com → ваш проект lrxipoykesieabacdcfn → SQL Editor → New query.
   Скопируйте туда ВЕСЬ файл supabase/migrations/0001_init.sql и нажмите Run.
   Должно появиться "Success. No rows returned".

2) Проверьте своего пользователя
   Supabase → Authentication → Users. У вас там два пользователя.
   Для входа нужен пароль. Если пароль не помните — задайте новый:
   откройте пользователя → Reset password (или создайте нового пользователя кнопкой Add user).

3) Откройте папку в VS Code
   File → Open Folder → папка dental-studio-cloud (там, где лежит package.json).
   Terminal → New Terminal.

4) Установите зависимости и запустите
   npm ci
   npm run dev

5) Откройте http://localhost:3001
   Войдите почтой и паролем пользователя из шага 2.
   Первый вход создаст ваши личные настройки на сервере.

6) Перенесите пациента
   Наряды → Новый наряд → создайте пациента прямо в форме.
   Или Пациенты → Добавить пациента.

Проверить, что всё работает: Настройки → Загрузить демо-пример.
Потом — Настройки → Очистить все данные, когда демо больше не нужно.

ПОДСКАЗКИ
---------
Тема переключается кнопкой в правом верхнем углу или в Настройках.
Файлы пациентов загружаются в Пациенты → кнопка «Файлы» у пациента.
На iPhone и других устройствах сайт заработает после публикации на Vercel —
это следующий шаг, скажите, и я подготовлю.

Файл .env.local уже заполнен вашими публичными ключами.
Ключ service_role в проект НЕ добавляйте никогда.
