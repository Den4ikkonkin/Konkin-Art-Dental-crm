## Ошибка «sh: tsx: command not found» или «sh: next: command not found»

Зависимости не установлены. Это разовая команда — выполняется один раз
после распаковки архива (node_modules в архив не кладут: это сотни мегабайт).

Откройте Terminal и выполните:

    cd "/Users/denis/Downloads/Konkin Art Dental"
    npm install

Ждите 1–3 минуты, пока скачиваются пакеты. Появится папка node_modules,
и команды заработают.

## Дальше — два терминала

Терминал 1 (сайт):

    npm run dev

Открыть http://localhost:3001

Терминал 2 (бот) — не закрывая первый:

    npm run bot

## Проверка, что всё встало

    ls node_modules | head

Должен показать список папок. Если пишет «No such file or directory» —
значит npm install ещё не выполнялся или пришёл с ошибкой.

## Частые ошибки

**«npm error path /Users/denis/package.json»**
Команда запущена не в папке проекта. Проверьте: `pwd` должен показать
/Users/denis/Downloads/Konkin Art Dental

**«npm ERR! code EACCES»**
Нет прав на запись. Не используйте sudo. Проверьте владельца папки:
`ls -la`

**«Не удалось войти в Supabase»**
Проверьте SUPABASE_EMAIL и SUPABASE_PASSWORD в .env.local.
Пароль можно сбросить: Supabase → Authentication → Users → ваш пользователь
→ Reset password.

**«В .env.local не хватает данных входа»**
Откройте .env.local — значения должны быть без кавычек-заглушек,
например SUPABASE_EMAIL=konkin.denis1996@yandex.ru

## Где что менять

    .env.local                  ключи и пароли (в git не попадает)
    NOTIFICATIONS.md            как устроены уведомления
    scripts/telegram-bot.ts     сам бот
    src/app/notifications/      страница «Уведомления»

## ОШИБКА: файл называется env.local (без точки в начале)

Самая частая причина. Next.js и бот читают только файл с точкой: .env.local

Проверить в терминале (в папке проекта):

    ls -a | grep env

Правильно:   .env.local        Неправильно:   env.local

Исправить одной командой:

    mv env.local .env.local

В Finder точка в начале скрывает файл — нажмите Cmd+Shift+. чтобы увидеть
скрытые файлы, и убедитесь, что имя начинается с точки.
