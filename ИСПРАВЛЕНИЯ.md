# Изменения — ноябрь 2026

## Выравнивание вёрстки

**Таблица «Врачи».** Заголовки числовых колонок стояли по левому краю, а
значения тоже — из-за этого столбец «Сумма» висел посередине без привязки
к правому краю. Добавлен класс `num` заголовкам, числа выровнены по правому
краю с табличными цифрами. Первая колонка забирает свободное место, числовые
сжимаются по содержимому.

**Карточки техников.** Подпись «Ждут примерки» переносилась на две строки,
цифра уезжала вниз. Теперь строка статистики — сетка
`minmax(0,1fr) auto`: подпись в одну строку с многоточием, число справа на
той же базовой линии. При ширине меньше 1500px статистика переходит в один
столбец, чтобы подписи не обрезались.

Кнопка «Портфолио» прижата к низу через `margin-top: auto` — карточки в
ряду одинаковой высоты независимо от содержимого.

**Карточки пациентов.** Блоки статистики (файлы, наряды, сумма, оплачено)
имели разную высоту из-за подписей в одну и две строки. Задана
`min-width: 74px`, подписи в одну строку, значения по верху. Кнопки справа
прижаты к верху и не растягивают строку.

**Строка наряда внутри пациента.** Переведена на сетку с фиксированными
колонками — номера не прыгают, даты и суммы выровнены.

## Кастомизация цветов

Администратор → «Оформление» → `/theme`.

- **4 готовых набора**: заводская, клиническая, тёплая, графит
- **12 цветов** в каждой теме: фон, панели, границы, текст, акценты
- **Предпросмотр** применяется сразу ко всему интерфейсу
- **Сохранение для всех** — запись в таблицу `app_theme`
- **Сброс** возвращает заводскую палитру

Как устроено: цвета хранятся в `app_theme` (одна строка на приложение),
при загрузке применяются как инлайн-переменные на `<html>`. Совпадающие с
заводскими снимаются, чтобы работали правила темы из CSS.

**Права.** Читают все вошедшие — цвета должны выглядеть одинаково у всех.
Меняет только администратор. Проверено: техник читает строку, но
`UPDATE` затрагивает 0 строк.
