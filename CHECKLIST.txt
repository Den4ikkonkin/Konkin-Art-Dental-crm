# ЧЕК-ЛИСТ: проверка уведомлений

Печать не нужна — идите сверху вниз. Каждый пункт отвечает «да» или «нет».

## 1. Бот запущен?

В отдельном окне терминала должно быть:

    npm run bot

Успешный запуск выглядит так:

    ✓ Вход выполнен: konkin.denis1996@yandex.ru
    ✓ Бот @Konkindenisbot запущен. Ctrl+C — остановить.

Если окно закрыто или в нём другая команда — бот не работает, и Telegram
не ответит ни на что. Это самая частая причина.

ВАЖНО: `npm run dev` и `npm run bot` — две разные команды в ДВУХ РАЗНЫХ окнах
терминала. В одном окне обе не запустить.

## 2. Чат привязан?

В Telegram отправьте боту ровно это, заменив КОД на код со страницы:

    /start КОД

Правильно:  /start RYAWEV
Неправильно: RYAWEV          (без /start бот не поймёт)
Неправильно: /start          (без кода бот только покажет инструкцию)

Ответ бота: «✅ Готово, чат привязан».

## 3. Сайт видит привязку?

Страница «Уведомления» НЕ обновляется сама. После привязки нажмите
кнопку «Обновить» или перезагрузите страницу (Cmd+R).

Признаки успеха:
- значок «Привязан» вместо «Не привязан»;
- появился ваш @username;
- кнопка «Проверить отправку» стала активной.

## 4. Сообщение доходит?

Нажмите «Проверить отправку». В Telegram придёт сводка с пометкой
«Проверка связи».

В журнале на сайте появится строка: тип «Проверка», статус «Доставлено».

## 5. Сводка по расписанию

Утром в 08:00 по Самаре бот пришлёт сводку сам.

Чтобы она не была пустой, в нарядах должно быть заполнено поле
«Приём» (дата и время), а не только срок готовности.

## Если что-то не так

**Telegram молчит** — бот не запущен (пункт 1) или введён не тот код.

**«Код не подошёл»** — код одноразовый. После успешной привязки он
стирается. Нажмите «Новый код» и повторите.

**Сайт показывает «Не привязан», хотя бот ответил «Готово»** —
нажмите «Обновить». Страница не следит за базой в реальном времени.

**«Проверить отправку» не нажимается** — чат не привязан (пункт 2).

**«Не удалось войти в Supabase»** — проверьте SUPABASE_EMAIL
и SUPABASE_PASSWORD в .env.local.
